# 驾驶营地

默认首页 `/`（或 `/?mode=hub`）从本地档案载入当前车辆，在旧试车场 (-11,19) 朝北出生。上方视口保留屏幕 60% 高度，前方从左到右是商店、装备、出击，建筑招牌、彩色停车区和小地图标记对应三处功能。原世界道路、边界、路面和碰撞继续使用，车辆按真实装配、等级及耐久驾驶。

单摇杆开入彩色停车框，松开摇杆，速度不高于 0.15、横摆绝对值不高于 0.1 rad/s 且连续停稳 0.7 秒后进入。高速路过、仍在推摇杆或驶离会打断计时。关闭界面后必须驶出停车区外扩 0.5 的范围，再返回停车才能再次进入，避免反复弹窗。

| 停车区 | 位置 | 功能 |
| --- | --- | --- |
| 商店 | (-15,13) | 购买零件、解锁底盘，消耗真实货币/废料并存入档案 |
| 装备 | (-11,13) | 底盘/外观俯视、正方格完整装备、装配方案、升级维修；保存后更新营地车辆 |
| 出击 | (-7,13) | 进入废弃货场准备页，确认后开始副本 |

商店和装备界面打开时清除摇杆输入、释放指针捕获并暂停营地模拟；关闭后保留实际运动、前轮、轮速、挡位/换挡阶段及控制历史恢复，燃料、电量和喷射冷却不重置。无法驾驶、缺件、损坏或耗尽营地燃料时，可用“拖车到装备区”恢复入口，拖车只重置位姿和运动，不补给资源或清除喷射冷却；在装备区购买、维修和重新装配。还原预设只使用拥有的部件，不会生成缺失件。

副本准备页可取消回营地；结算保存成功后可返回营地，并按结算后的库存和耐久初始化。保存失败时保留重试入口，返回按钮禁用。独立练习入口为 `/?mode=practice`；既有 `/?validate=1` 和 `/?test=1` 保留驾驶验证兼容入口。

验证命令：`npx vitest run tests/unit/hub.test.ts`、`npx playwright test tests/e2e/hub.spec.ts`。浏览器覆盖实际摇杆从出生点驶入、停稳、暂停、关闭后不重开、交易、装配更新与刷新、坏车拖车恢复、副本返回及 320/390/430 竖屏。截图位于 `openspec/changes/add-driving-hub/evidence/`。开发专用 `/?mode=hub&test=1` 暴露 `window.__hub` 快照和定位钩子，正式构建不提供；浏览器结果不替代真实手机验收。
