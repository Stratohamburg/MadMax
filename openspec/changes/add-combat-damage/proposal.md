# Proposal

## Why

游戏的爽感来自后期倍率提高后的大量弹丸与巨额伤害，同时需要敌人、血量、装甲、碰撞伤害等基础战斗循环。需要一个高吞吐、确定性、可测试的战斗核心，并尽早在手机上验证性能上限。

## What Changes

- 新增战斗实体：玩家车辆、敌人、弹丸、爆炸/范围效果；血量、装甲（内/外层装甲与外挂部件耐久）。
- 新增伤害管线：基础伤害 → 倍率栈（加算/乘算分层）→ 暴击 → 抗性/装甲减免 → 结算。
- 新增外挂部件受击与脱落、碰撞伤害（利用现有碰撞冲量）。
- 新增弹丸池、空间哈希与上限策略，以支持大量弹丸；伤害数字与特效事件聚合输出。
- 新增手机性能压测基准（弹丸数量、敌人数量、帧时间）。
- 不改变渲染方案（继续 Canvas 2D，仅输出渲染所需的最小数据）。

## Capabilities

### New Capabilities

- `combat-damage`：战斗实体、伤害管线、装甲/外挂耐久、弹丸池与确定性战斗步进、性能预算。

### Modified Capabilities

无。

## Impact

新增 `src/combat/`（实体、伤害、弹丸、空间索引）与压测脚本；需与现有场景/碰撞模块对接，战斗步进接入固定外层时钟。依赖 `add-auto-weapons` 的开火事件，被 `add-roguelike-modifiers` 与 `add-pve-extraction-mode` 使用。
