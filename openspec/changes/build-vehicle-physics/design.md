# Design

## Context

动机见proposal。v1实际状态硬保护会冻结积分，低速参考拉回、漂移改抓地与碰撞清空状态会覆盖物理结果。旧证据不作为v2通过证明。

## Goals / Non-Goals

建立模式无关物理、有限执行器、普通防失稳和可放宽的漂移控制。十车型共用规则，保留单指期望输入和三路面。悬挂、挂车、四轮独立动力和实车标定不在范围。

## Decisions

1. Intent进入控制器，输出前轮目标、驱动、制动和后轴制动。物理kernel的类型及实现均不接收普通/漂移、路线或目标速度。机械转角/速率、动力和抓地预算是能力；实际beta/u/speed/r不按目标截断。
2. 车身三自由度加前后等效轮速。接地点速度包含横摆贡献；组合滑移产生反对轮胎相对路面滑动的摩擦，驱动/制动扭矩和轮胎反作用推进轮速。固定1/120外步，稳定接触求解及固定子步与加倍精度对照。
3. 普通控制器由车型、速度、载荷和路面抓地估计稳定前轮包络，包含预测余量及牵引限制；漂移放宽转向与滑移包络。限制只作用于请求，不能约束真实姿态。既有失稳连续恢复，允许失败。
4. 速度闭环有明确响应时间与饱和，路线预测区分运动角与车头横摆。低速由接地点摩擦求解停车；纯旋转继续耗散。几何圆弧仅作参考/验证，不强迫车辆跟随。
5. 能量包含车身及车轮，记录动力功、制动、滑移、阻力和碰撞损失并核对残差。无意图夹角扣速。
6. OBB车身与矩形/边界接触，平移旋转扫掠及接触点冲量影响平移和横摆；零恢复系数和有界接触摩擦。不根据输入选择沿墙方向，不注入最低速度，不清整组历史。
7. 快照包含有效profile、模拟时间、物理和控制历史。各轴胎痕依据实际接地点滑移，质心速度/侧滑不是必要条件。网页区分目标、执行器、模式请求与实际漂移。

## Implementation Contract

| 层 | 输入 | 输出/权限 |
| --- | --- | --- |
| 输入 | 摇杆、滞回、当前车型最大目标 | 世界路线、目标速度、漂移请求；不写车辆状态 |
| 控制 | 实际状态、轴能力、Intent、控制历史 | steeringTarget/drive/brake/rearBrake；仅限制请求 |
| 机械执行器 | 前轮目标、动力和制动比例 | 机械转角、轮速扭矩；同样的命令不分普通或漂移 |
| 物理 | PhysicalState、Actuation、PhysicalProfile、路面与dt | 世界速度、横摆、轮速、位置和连续车头角；无模式/目标接口 |
| 场景接触 | 前后物理状态、车身几何、矩形世界 | 接触点冲量与几何脱离，累计碰撞损失 |

前后轴接地点速度为 `vCG + r × arm`，转入各轮胎坐标后以 `transport - radius × omega` 和侧向滑速构成组合滑移。隐式柔顺性与包含横摆、车轮反作用的有效质量共同求冲量，再投到二维抓地椭圆，两个轴和制动约束交替迭代12次。正则速度只用于接触刚度的分母，不能覆盖实际速度或姿态；旧轮胎松弛和硬保护字段删除。

普通前轮包络估算为 `atan(L × availableGrip × g × gripReserve / speed²)`，再与机械行程取小；可用抓地结合当前轴载荷与路面。路线率参考有抓地上限与响应时间，反馈以实际运动方向、侧滑和横摆为依据，期望路线不可达时保留跟踪误差。纵向速度闭环响应时间0.55秒，牵引余量随横向需求变化，直行不固定牺牲半数抓地。漂移增加控制包络和侧滑参考，并反馈调节后轴制动；物理轮胎参数始终相同。

能量独立累计轮胎冲量与接触点前后平均滑速的乘积，驱动/制动扭矩作用的轮能变化，以及阻力、碰撞损失；核对车身平移、横摆与等效轮动能之和。每步记录数值残差，禁止通过扣速或只改账本伪造损耗。

## Frozen Validation

普通矩阵为十车×三路面×20%/50%/100%最大目标速度×90°/180°/0.5秒左右换向，每场6秒；45°为回归失败门槛，不是物理状态限值。已有95°侧滑、强横摆和普通模式后轴失抓地单独验证连续惯性及允许spin。跑车/拉力以初速8、路线1.2rad/s入漂6秒再退出3秒，要求实际反打、连续至少1秒反向侧滑、速度损失和连续退出。每车验证84°/95°/170°及纯旋转的无动力能量，30/60/120调度一致，1/240对1/480精度误差小于5%车长与2°。七对车型以公共速度和三种路线辅助比较，至少两指标族差异达到15%。

## Risks / Trade-offs

- 新接触及轮速增加数值敏感性：以能量收支、低速停车、镜像和子步收敛验证。
- 普通模式不保证任意外部冲击下稳定：冻结十车型三路面低中高速度急转/快速反向矩阵，并独立验证已有失稳及撞击惯性不会被清除。
- 十车型需重调：先冻结统一物理，再调控制，旧恢复窗口不自动沿用。

## Migration Plan

合同和物理测试先行，再接控制器、碰撞、网页和快照，最后生成v2独立证据。拒绝旧配置/快照；baseline仅作历史测试。真机驾驶保持单独验收。
