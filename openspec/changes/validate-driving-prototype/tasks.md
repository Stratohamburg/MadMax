# Tasks

以下跟踪第一阶段实施与验收工作。复选框表示已完成且已验证的任务；证据见 acceptance.md，真实手机人工驾驶单独验收，未执行项目保持未完成。

## 1. Client Foundation

- [x] 1.1 建立 TypeScript、Vite 与 Canvas 2D 客户端，配置开发、静态构建、类型检查、Vitest 和 Playwright 命令；以 `npm run build`、`npm run typecheck` 成功及开发页可加载验证。
- [x] 1.2 建立独立于绘制的 1/120 秒物理时钟、带时间标记的输入入口和暂停恢复机制；用确定性时钟测试验证正常 30/60/120 FPS 不丢步、隐藏期间不补算、异常长帧积压有上限。
- [x] 1.3 在项目说明中补充启动、构建、测试与同一局域网手机访问开发页的方法；按文档逐条执行可用命令并记录实际使用入口，不要求发布公网。

## 2. Vehicle Dynamics

- [x] 2.1 建立车辆状态和集中参数配置，实现目标速度追赶及非线性加减速；用低速与高速区间比较、半速稳定、目标夹断和有限时间停车测试验证，不吞掉合法微小正速度。
- [x] 2.2 实现普通与漂移的速度相关转向曲线、零速无转向、最短角弧和精确 180°选择规则；用侧向起步、微小目标角、179°跨界和重复正后方输入验证不原地转头、不越过目标且选择稳定。
- [x] 2.3 分离车头与运动方向，实现普通抓地、漂移侧滑、低速收敛和退出恢复；用相同初始状态下两种模式的路径差异、退出瞬间状态连续及侧滑角始终小于 90°验证。
- [x] 2.4 实现小角度免损、90°封顶及漂移更大的转向损失，并在动力更新后扣除；用固定原始状态的不同夹角与模式比较，以及满油门急转掉速测试验证。
- [x] 2.5 提供默认测试车参数及单位、合法范围、规则不变量的说明；核对说明与配置一致，并验证修改同一组参数后可重现对应速度与转向差异。

## 3. Mobile Driving Input

- [x] 3.1 建立竖屏布局与按完整漂移圆自适应的固定中心摇杆；通过 320×568、360×640、390×844 视口与安全区检查验证主视图至少占 60%、所有方向可触达漂移环，尺寸变化时清除输入。
- [x] 3.2 用 Pointer Events 将任意非零位移映射为正目标速度和屏幕目标方向，支持真实距离与越界捕获；以中心、微小位移、R/2、R、远端及斜向拖动测试验证零死区和不滚动页面。
- [x] 3.3 实现普通满油门缓冲、漂移进入退出阈值和视觉状态反馈；测试由内向外、入漂后轻微回收、收回退出及全部方向，验证滞回期间不抖档、漂移无额外速度加成。
- [x] 3.4 实现单活跃触点、额外触点忽略、抬起取消、捕获丢失和页面隐藏清理；以浏览器输入生命周期检查验证无旧油门残留、不向第二触点移交、恢复后需重新触碰。
- [x] 3.5 补充玩家操作说明，说明距离、方向、满油门缓冲和漂移外拉；按说明完成一次半速行驶与漂移进出，验证文字和实际输入状态一致。

## 4. Driving Playground

- [x] 4.1 绘制可辨认的直道、缓弯、急弯、连续弯和少量静态障碍，接入固定方向跟随镜头；在浏览器驾驶各区域并检查截图，验证镜头不随车头旋转、轨迹可观察。
- [x] 4.2 实现圆形车辆与静态障碍、边界的扫掠接触检查及可通行切向位移；测试最高速度不穿透、碰撞归零不反弹、有可通行接触面可脱离，以及完全阻挡时不提交原地旋转。
- [x] 4.3 按轮胎世界位置与实际侧滑生成拖尾，设置寿命和容量上限；用直线入漂、侧滑转弯、退出后的残余侧滑和持续生成测试验证反馈合理且数据有界。
- [x] 4.4 提供 HUD 与完整重置，恢复出生位置、两种方向、速度、转向历史、镜头、输入和拖尾；通过漂移中重置的集成测试验证旧触点不重新接管且可以重新开始驾驶。
- [x] 4.5 在驾驶说明中标注各场地区域对应的验证用途与碰撞重置规则；逐项在场地找到对应区域并按说明完成一次练习。

## 5. Observation and Tuning

- [x] 5.1 增加显式开启的验证模式，展示三种方向、实际与目标速度、漂移状态、夹角和转向减速贡献；通过满油门急转与退出漂移观察验证数据对应真实状态，普通界面保持驾驶所需信息。
- [x] 5.2 提供参数调整、合法值校验和应用后重置，说明开启方式及参数单位；测试非法参数不生效、合法参数从相同出生状态生效，并可恢复默认配置。
- [x] 5.3 在本变更目录建立 `acceptance.md` 验收记录，列出设计矩阵、参数版本、设备浏览器及通过/失败/未执行状态；检查每项规范都有对应检查项，所有尚未执行的项目保持未执行标记。

## 6. Integrated Validation

- [x] 6.1 对完整物理链路回放同一段覆盖直行、普通转向、漂移、退出与松手的 10 秒输入，比较 30/60/120 FPS；验证位置差不超过车身长 1%、速度差不超过 Vmax 的 0.5%、两种朝向差不超过 0.5°，将结果记入验收记录。
- [x] 6.2 运行 `npm run typecheck`、`npm run test -- --run`、`npm run test:e2e` 和 `npm run build`，完成三个目标视口的整体驾驶、触控中断、碰撞与重置回归；记录运行结果与未解决缺陷，不以截图代替交互检查。
- [ ] 6.3 在至少一台真实手机浏览器评估普通满油门保持、主动进出漂移、侧滑可控性、小幅修正保速和连续弯，记录设备版本、参数、误触与不适；调校后重跑受影响检查，无实机条件时保持本任务与整体验收未完成。
