# Design

## Context

当前 `PhysicalProfile` 假定质心近似位于几何中心，轴距分配由 profile 固定参数给出。改装后质心可大幅偏移，必须成为一等参数。

## Decisions

- **管线**：`底盘 + 装配 → compose() → PhysicalProfile(v3) + 武器挂点`，纯函数，位于核心之外，核心不感知装配。
- **格→米**：采用全局常量格边长；部件质量按其占用格中心集中成点质量，再做平行轴累加（不细分形状）。
- **质心参与**：几何模块以质心为参考计算前后轴到质心距离及车身碰撞轮廓偏移，其余动力学公式保持原形。
- **参数叠加规则**：flat → 加算 → 乘算三层，与肉鸽加成共用同一规则，避免重复实现。
- **喷射**：执行器增加助推通道；控制层在高目标速度且车头与路线对齐时自动请求，保留单摇杆驾驶，受冷却、持续时间和能源约束，计入能量账本。
- **版本**：profile-3，旧版拒绝；保留 v2 基准作为"空装配等价"回归：空装配派生结果应与 v2 十车型行为一致（容差内）。

## Risks / Trade-offs

- 回放哈希与审计需整体更新；用空装配等价回归控制风险。
- 过大质心偏移可能导致控制器稳定矩阵失效；需扩展稳定性验收包络或对装配性能设软上限。

## Implementation Contract

- 沿用装配的 0.12 game-L 格与 1000 kg = 1 game-M 质量换算；部件位置取旋转占格的平均中心。底盘基础质量不含新增部件，空装配保留基础模型用于回归；出击时另校验驾驶座、发动机、变速箱、油箱和非前置驾驶位的潜望镜。
- profile-3 增加横向质心字段；纵向偏移转换为前后轴距比，横向偏移同时作用于轮胎接地点速度、力矩、车轮与碰撞轮廓。状态位置始终为质心，几何轮廓围绕质心偏置。
- 总惯量为底盘原惯量与全部质量相对新质心的平行轴项；物理参数按现有范围截断，返回每个字段的原值/最终值和告警。质心偏移不得静默丢弃，边界截断显式列入摘要。
- 统一属性求值放在无 DOM 公共模块，flat→increased→more，按稳定来源 ID 排序；肉鸽模块后续复用，compose 不自行再实现倍率栈。
- 动力链状态独立于刚体状态，包含挡位、目标挡、RPM、换挡剩余时间、油量；按驱动轮角速度和总传动比求目标 RPM，线性插值扭矩曲线，受额定功率、红线和变速箱扭矩上限限制。原始 Nm 内容值按 2500 Nm = 1 game-M·game-L²/s² 标定，不宣称实车还原。
- 自动升挡阈值为红线的 86%，降挡为 35%，换挡期间轮端驱动力为零，接合时 RPM 依目标齿比回落。部件供给最大值与运行时剩余量分开；发动机/传动状态可序列化，与固定外步同步推进。
- 外力接口同时支持世界力/力矩和挂点冲量。外力与喷射的功分别记账；外部冲量的能量差记录为 externalWork，刚体和轮胎耗散不吸收该来源。
- 先捕获 v2 十车型直行、转向和漂移的数值 fixture，再升级版本。未装动力链的基础车型继续走相同驱动曲线；有装配的游戏会话通过动力链执行器提供轮端力，避免改变空装配基线。
- 喷射控制在同一固定时钟运行，持续耗能，持续时间耗尽开始冷却；能源不足停止；无新增瞄准、开火或喷射按钮。

## Verification

旧版本拒绝与快照恢复、二维质心/几何/冲量能量、三十组 v2 fixture、换挡断动力/RPM、扭矩限幅、缺失动力链、重载衰减差异及喷射持续/冷却分别由单测验证。核心基准、审计和网页回放写入本变更的 v3 新目录，不覆盖 v2 证据。
