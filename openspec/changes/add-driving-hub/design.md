# Design

## Context

见 proposal.md。现有入口为驾驶验证场与副本准备页，CanvasRenderer 可接收地面绘制函数，装配驾驶和档案事务已经可复用。

## Decisions

- 默认 `/` 为营地，`?mode=hub` 显式选择营地，`?mode=practice` 保留驾驶验证场；已有 validate/test 查询继续支持调试，营地测试使用 mode=hub&test=1。
- 保留现有世界边界、道路和碰撞。出生 (-11,19)，朝北；商店 (-15,13)、装备 (-11,13)、出击 (-7,13)，停车区各 2.8×2.8。营地镜头向前偏移 3.8，纵向视野 20，使 320 宽视口也能看清三处区域。绘制仓棚、停车边线、地面标识与方向指引，小地图显示功能点。
- 区域触发器为独立纯函数，固定 1/120 步推进：区域内速度≤0.15、横摆≤0.1 rad/s、输入 targetSpeed≤0.01 且 angle=null，持续0.7秒；任一条件失效重置计时。触发后锁定区域，离开区域外扩0.5边界才重新解锁。
- 营地复用 AssemblyDrive 和扫掠碰撞，使用档案耐久/等级。不新增战斗。对话框打开时暂停时钟并清除输入，关闭后保留完整刚体、动力链、燃油、电量和冷却状态；实际改装调用核心质量迁移，容量增加不补满。
- Workbench 返回 dialog 供营地监听关闭；独立商店复用购买/解锁事务。坏车可拖至装备区，避免缺动力导致无法恢复。
- 出击使用现有副本页面与已保存 active 装配；结算成功后返回默认营地。不复制副本模拟和存档逻辑。

## Risks / Trade-offs

- 停车容易反复触发 → 区域离开后重新解锁。
- 商店/装备打开时摇杆仍被按住 → 清除捕获和输入，并暂停模拟。
- 玩家装配无法驾驶 → 提供拖车恢复，装备页仍可购买缺件并维修。

## Lifecycle Revision

商店和装备开关仅暂停固定时钟与清输入，不创建新的 AssemblyDrive。同一底盘改装通过核心迁移保持车身位置与运动；更换底盘为显式车库换车，保留场景位置并停止，供给只保留不补满。拖车显式移动/停止车辆并保留资源和冷却。只有初次进入场景才按容量初始化。
