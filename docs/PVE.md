# 副本搜打撤

从默认营地 `/` 的出击停车区停稳后进入，也可直接打开 `/?mode=pve`；独立驾驶练习位于 `/?mode=practice`。准备页选择车型/装配并查看损失规则，确认后仅使用一个摇杆；瞄准、开火、搜刮、维修补给、撤离均自动触发。取消准备或结算保存成功后可返回营地，营地使用结算后的真实库存与耐久。

废弃货场限时 180 秒，携带 8 格。沿 x=-11 公路向北有三组物资；南侧 (-11,24) 出口 20 秒开放，北侧 (-11,-29) 出口要求击败 70 秒出现的 Boss。进入绿色范围停留 5 秒，离开即重置。(-16,13) 营地修复内部件/车体并补充燃料弹药，已脱落件不会复活。

3、8、15 击杀及军需仓库触发三选一，选择期间逻辑暂停，候选最多刷新三次，升级不跨局保留。Boss 击杀后成功撤离发出主线和关卡解锁。

敌人波次在0、12、24、40、60、90、120、150秒刷新，循环使用步枪兵、机枪皮卡、火箭兵和机炮装甲车；70秒出现加农炮首领铁甲督军。机枪碉堡(-8,9)与火箭哨塔(-15,-7)开局已部署，守住北向路线。建筑不追击，步兵与敌车在各自距离停下来射击；所有敌人都有实际武器、弹道及命中反馈。车辆可高速撞死步兵，但车体也扣血，完整参数见 [战斗配置](COMBAT.md)。

失败损失携带物，原装配按实例排序逐件以 25% 概率损失；已脱落件必失。结算含唯一 runId、带出物、耐久、损失、经验、货币、击杀、伤害和用时。终局冻结，结算由档案系统原子入档。

`src/modes/pve/run.ts` 是生命周期和规则；`level.ts` 定义数据与独立种子生成；`session.ts` 编排 1/120 秒模拟。波次池满时排队，不静默丢失。模块吸伤、动力链、共用电池、后坐力、碰撞被动、局内升级、维修均消费现有系统契约。

验证：`npx vitest run tests/unit/pve.test.ts tests/unit/combat-roster.test.ts`。开发专用 `/?mode=pve&test=1` 提供 `window.__pve` 快照、初态移动、终局、敌人生成、战斗展示快照与暂停钩子，正式构建不暴露。
