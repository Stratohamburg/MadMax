- [ ] 1.3 增加可关闭的阶段计时与接触／查询／状态创建计数，区分包含耗时与独占耗时，配套 CPU／分配采样命令；验证诊断开关不改变状态、事件和随机序列，文档说明插桩结果不用于正式预算。
- [ ] 1.4 建立冻结参考实现／轨迹的逐步差分入口，记录浮点容差并精确比较事件、命中、死亡、挡位、随机和离散资源；验证故意注入状态差异或漏事件时检测失败，旧 v5 fixture 与证据保持不变。
