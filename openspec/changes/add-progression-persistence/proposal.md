# Proposal

## Why

改装、搜打撤与主线都依赖跨会话的玩家数据：部件仓库、已保存的装配方案、货币与解锁进度。需要一个版本化、可迁移、抗损坏的本地存档与局外成长模型。

## What Changes

- 新增玩家档案：部件仓库、装配方案（多套）、货币/材料、解锁（底盘、部件、关卡）、主线进度、统计。
- 新增本地存档：版本化 schema、校验、迁移、损坏检测与备份回退。
- 新增局外成长：结算结果入档、部件获取与升级、装配方案保存/加载。
- 新增存档事务：副本结算原子写入，避免中途退出导致战利品复制或丢失。
- PVP 数据（对战记录、匹配）不在本期。

## Capabilities

### New Capabilities

- `progression-persistence`：玩家档案模型、本地存档、版本迁移、结算入档、装配方案管理。

### Modified Capabilities

无。

## Impact

新增 `src/persistence/` 与档案模块；使用浏览器本地存储（具体介质在设计中确定）。依赖 loadout（装配清单）与 pve-extraction-mode（结算）。会话外保存的数据格式须稳定，后续任何变更需提供迁移。
