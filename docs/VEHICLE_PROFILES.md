# 十车型与三类路面

十车型使用 `vehicle-profile-2`，修订均为 `2`，模型为 `vehicle-physics-2`。完整参数由 `profiles.ts` 从参考配置生成，每份 profile 均独立可复制。名称、类别、验收元数据不参与物理分支。

| 配置 ID | 特点 |
| --- | --- |
| light-pickup | 轻型皮卡，中等轴距、后驱和较快转向 |
| heavy-pickup | 更大质量、较低动力重量比、部分前轴驱动 |
| van | 前驱、温和前轴响应 |
| box-truck | 长轴距、较弱制动、较慢执行器 |
| truck | 大占地、低动力重量比、较大横摆惯量 |
| heavy-truck | 最长刚性车身、最慢转向和最低动力重量比 |
| sports-car | 后驱、快速转向、高干地抓地 |
| rally-car | 四驱、更快执行器和松散地适应性 |
| muscle-car | 较强动力、较慢转向和较弱后轴刚度 |
| off-road | 四驱、较高质心、低目标速度和松散地适应性 |

轮胎参数与路面共同决定实际抓地，不受普通/漂移模式修改。每个接地点独立按世界坐标和模拟时间采样；干硬路 ID 为 `dry-hard`，松散地为 `loose`，湿滑地为 `wet`，格式为 `vehicle-surface-1`。轴载荷由上一物理纵向加速度引起的准静态转移决定，载荷非负，总和为 mg；此处约束接触载荷，不改写真实速度或加速度。

前轮机械行程、响应和速率来自物理执行器参数。普通控制器结合轴距、速度、可用轴载荷和路面估计前轮包络与牵引余量；漂移仅放宽控制请求并使用后轴制动。平直路段不固定牺牲一半牵引力，转弯时按横向需求留出抓地余量。

参数、单位和校验规则见 [PARAMETERS.md](PARAMETERS.md)。所有完整参数、规则、版本、源码哈希和轨迹保存在 `build-vehicle-physics/evidence/vehicle-physics-2/<profileId>/2/`。

基准覆盖每车三路面 × 三速度（最大目标的20%/50%/100%）× 90°急转、180°急转及0.5秒换向，共270个普通驾驶场景；稳定初态下最大侧滑须小于45°，不得spin。该门槛用于发现控制失稳，不是物理角度限制。已有95°侧滑和强横摆的普通接管另行验证惯性连续性，不要求保证救回。

跑车和拉力另测左右持续入漂、实际反打、至少1秒反向侧滑、实际速度损失和连续退出。能量矩阵涵盖84°、95°、170°和纯旋转，逐步检验无动力不增能及功/耗散闭合。十车均比较30/60/120FPS和1/240对1/480子步。

七对相近车型在公共速度下对比关闭路线辅助、公共辅助、最终辅助三组。指标包括加速、制动、几何半径、路线响应、实际执行器10%～90%响应、侧滑与路面跟踪。执行器响应通过实际机械命令测量；同一指标族不重复计数，近零值不计相对差。至少两族达到15%差异的检查用于防止参数被控制器过度掩盖。

```powershell
npm run physics:benchmark
npm run physics:audit
```

v1的冻结对齐时间、非零松弛开关和硬保护指标已经被v2合同替代；历史文件只作追溯。当前没有悬挂、挂车、四轮独立动力或实车参数标定。真实手机手感单独验收。
