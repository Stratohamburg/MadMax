# 车辆物理 v4 职责修订与验收

日期：2026-11-01。本记录对应本轮核心与装配接入修订；原 acceptance.md 和 v1/v2/v3 证据保持只读历史。

## 理念与归属

摇杆表达期望，控制器仅下发有限执行器请求。普通/漂移策略不进入刚体、轮胎、机械动力链或接触求解；碰撞、已有失稳、超目标速度和大于 90° 的侧滑仍允许存在。普通驾驶矩阵是控制器支持域验收，不是结果限制。

| 能力 | 规范归属 | 实现 |
| --- | --- | --- |
| 发动机扭矩/功率/红线、变速箱齿比/效率/承载、自动换挡、有限助推 | build-vehicle-physics / vehicle-physics | physics/mechanics.ts |
| 二维质心、参考点迁移、外力、实体接触及能量收支 | build-vehicle-physics / vehicle-physics | physics/reconfigure.ts、body-contact.ts、physical.ts |
| 部件、健康、加成、质量/惯量/挂点和资源容量派生 | add-assembly-physics | loadout/compose.ts |
| 期望路线/速度、普通包络、漂移策略与助推触发请求 | 控制器 | physics/assist.ts 与 assembly-drive.ts 接入 |
| 伤害、脱落、实际运动事件、补给、暂停和拖车 | combat / PVE / hub | 对应模式编排 |

机械公式已经移入核心，装配不保留第二套运行公式。性能加成先进入发动机有效参数，再受到功率和变速箱限幅。控制器用当前轮速、挡位和供给下的实际可用轮端力换算请求。

## 修正行为

- 加成不再绕过变速箱扭矩上限，诊断扭矩与执行力一致。
- 没油、换挡或发动机毁坏不冻结仍可用的转向/制动，不清空惯性。
- 装卸部件按二维质心差迁移参考点及速度，保持剩余车身、挂点、各点瞬时运动、横摆和轮速连续。质量携带能量单独记为 configurationWork。
- 质量、质心、惯量不分别截断。超出支持域明确拒绝；工作台阻止使用，旧档案仍可打开工作台恢复，不抹掉库存。
- 真实 OBB–圆实体接触产生冲量、横摆和动量交换；固定建筑使用零逆质量。撞击伤害使用真实接触结果，伤害冷却不停止物理接触。
- 漂移/速度/助推事件消费实际物理状态和执行器输出。仅发出漂移请求不足以生成实际漂移事件。
- 营地停车同时检查平移与横摆。打开/关闭界面保留运动、前轮、轮速、挡位、换挡阶段、资源与冷却；拖车是显式运动重置且不补给。

## 模型边界与未执行项

动力链使用理想怠速离合、无独立曲轴惯量、仅前进挡；未模拟发动机制动、手动离合或差速器。单位和曲线是游戏标定，不是实车参数。最高目标速度是控制输入/能力估计，实际速度可能更高，负载也可能使车辆达不到目标。

圆实体当前采用固定步离散接触，未实现高速连续扫掠；静态场景使用包含旋转的 OBB 扫掠。普通稳定性结论限于所列稳定初态和装配，不保证任意撞击、任意重载或已有失控都能被控制器救回。超出当前质量几何支持范围的装配明确拒绝。

真实手机驾驶手感、触控和战斗性能仍待设备验收；对应两项待办保持未完成。本轮物理职责修订共 11 项任务完成，其他并行功能的待办仍由各自 change 跟踪，不自动归档。
