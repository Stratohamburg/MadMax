# Proposal

## Why

车辆控制已可用，但车辆只能从十个固定车型中选择。改装是游戏的核心成长与 build 载体：玩家在车体俯视图上摆放零部件与武器，摆放位置决定后续的质心、武器射界和风险。需要先定义纯数据、无 DOM 的格子装配模型，供物理、武器、存档和 UI 共同消费。

## What Changes

- 新增底盘格子定义：每个底盘由**内层（车体内）**与**外层（车体外）**两个格子层组成，格子带槽类型、不可用格与朝向。
- 新增部件数据模型：多格形状、可旋转、槽类型、质量、能耗、标签、相邻关系。
- 内层摆放车辆自身部件（动力、传动、轮胎、喷射系统、油箱、核心、内装甲等）；外层摆放武器、外装甲与外挂部件（外挂部件同样占用外层格子并有外露属性，可被击落或丢失）。
- 新增装配合法性校验与摆放操作（放置、移动、旋转、移除）及可序列化的装配清单。
- 不含 UI 绘制、物理换算、武器行为与存档（由其他变更负责）。

## Capabilities

### New Capabilities

- `loadout-grid`：底盘两层格子、部件形状与槽约束、摆放校验、装配清单及其稳定序列化。

### Modified Capabilities

无。

## Impact

新增无 DOM 模块（如 `src/loadout/`）与单元测试；不修改 `src/vehicle/physics`。后续 `add-assembly-physics`、`add-auto-weapons`、`add-progression-persistence` 依赖本能力的装配清单与坐标合同。本变更是改装系列的起点。
