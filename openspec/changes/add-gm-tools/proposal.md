# Proposal

## Why

初始车辆应能直接驾驶和使用机枪；旧档案的损坏状态与营地未绘制武器使初始体验难以确认。原型调试还需要直接发放物资、修复装备和重置数据的可见入口。

## What Changes

- 验证新建及重置档案的所有初始部件满耐久，默认安装一挺机枪、弹药箱及必要动力部件。
- 营地绘制真实挂载武器，保持车辆位置和朝向一致。
- 营地主界面新增 GM 面板，发放货币、废料和指定数量的满耐久零件，并支持一键修复库存。
- 重置需在面板明确确认；原子替换主存档、备份并清除待处理结算，恢复初始车辆与资源。

## Capabilities

### New Capabilities

- `gm-tools`：本地原型的 GM 物资发放、修复、重置与默认车辆验证。

### Modified Capabilities

无。

## Impact

修改档案事务、营地武器呈现与界面；新增 GM 数据操作及面板、单元和浏览器测试、使用文档。不引入新依赖，已保存的正常战斗损耗继续保留，显式修复或重置才恢复。
