# Proposal

## Why

底盘双层装配（`add-vehicle-loadout-grid`）、动力链与换挡（`add-assembly-physics`）、自动武器（`add-auto-weapons`）与两段式损毁（`add-combat-damage`）均为无 DOM 的纯数据与核心逻辑。玩家需要直观的操作界面来组装车辆，并在战斗中实时感知部件损伤与武器射界。现有界面仅包含单摇杆驾驶验证场，缺少改装工作台、战斗态车辆状态图（纸娃娃）以及不遮挡车身的射界可视化系统。

## What Changes

- **新增改装工作台界面（Loadout Screen）**：
  - **双层视图切换**：提供车内剖面层（车体内构：发动机、变速箱、电池、油箱、座舱）与车顶外饰层（车顶武器、防滚架、外挂装甲，几何外扩一圈）的层级切换与半透明透视模式。
  - **车辆俯视与一体部件**：底盘/外观俯视使用同一正方格坐标；车头、四轮、车身或底盘可辨认，多格装备使用联合轮廓和单件图形，拖拽时整体操作。
  - **拖拽与预设交互**：支持部件拖拽摆放、90° 旋转、卸下，以及一键载入/还原当前车型出厂预设配置（Stock Presets）。
  - **性能预览看板**：实时显示当前装配的总质量、质心偏离、动力与极速评估、全局供电与弹药余量。
- **新增战斗车辆状态图（Vehicle Status Paper Doll HUD）**：
  - 放置于战斗主视口左下角，与右上角小地图形成对角线对称布局，不遮挡中央驾驶视线。
  - 以紧凑的微缩车辆剖面图实时显示各模块健康度：正常（绿色）、受损（黄色闪烁并提示马力折半等状态）、毁坏（红色打叉/脱落）。
- **新增 Canvas 动态射界与装填状态渲染（In-Game Firing Arc Visuals）**：
  - 在世界坐标地面投影武器射界扇形与锁定准星。
  - **车身周围净空保障**：车身 1.5 倍半径内保持完全净空，确保车体朝向、前轮转角与漂移侧滑姿态清晰可见，严禁遮挡车身本身。
  - **状态外沿化呈现**：将武器装填进度与过热警示光弧附着于射界最外侧圆弧边缘（Arc Rim），消除车顶堆砌进度条的杂乱感。

## Capabilities

### New Capabilities

- `vehicle-ui`：双层改装工作台界面、出厂预设加载与拖拽交互、左下角车辆状态纸娃娃 HUD、Canvas 射界净空与外沿装填渲染器。

### Modified Capabilities

无。

## Impact

本次补齐战斗中的九种武器实体与炮台旋转，射界内绘制当前指向细线；敌方车辆、步兵和碉堡有独立外形，双方射击均显示枪口、弹丸、拖尾与命中效果。

新增 `src/ui/loadout/`（改装界面 DOM 与样式）、`src/ui/hud/`（纸娃娃状态图）及 `src/render/weapons.ts`（射界与弹药外弧渲染）。消费 `loadout-grid`、`auto-weapons` 和 `combat-damage` 的数据接口，接入现有竖屏主视口与单摇杆交互流程。
