# 驾驶练习与验证入口

本文说明网页当前接入的 `vehicle-physics-1` 驾驶链路、验证场入口以及仍保留的 `baseline-1` 历史证据。网页默认使用跑车 profile；核心和网页通过同一个权威状态推进，核心单元通过不替代浏览器和手机验收。

进入网页就能开车。右上角 `?` 可随时打开操作说明。摇杆中心固定，屏幕方向就是想去的方向，镜头只跟随车辆位置。车头会逐渐转向；推向后方会向前转弯掉头。

1. 从中心向上推到实线内环一半，目标为半速；车辆需要时间加速，保持后能稳定半速。任意微小位移都有速度，精确回中才是零输入。
2. 实线内环是普通满油门，再向外还有缓冲行程。缓冲区能保持最高目标速度，且仍是普通抓地。
3. 继续推到外侧虚线环，进入漂移；轻微回收仍保持漂移，收回点线退出环以内恢复普通满油门。所有方向均可外拉，不需要额外按钮。
4. 漂移时车头、前轮和路线由核心辅助控制器连续调整，允许车头偏向弯内并自动反打；退出时 `h`、侧滑和横摆逐渐恢复。小幅转向保速，大角度转向会掉速，漂移代价更大。满油门只表示目标速度，HUD 是实际速度。
5. 松手逐渐停车。触控取消、页面切走、尺寸变化会清除输入，回来需重新触碰。

地图右上角小地图数字对应以下区域，点表示车辆当前位置，北方向始终向上。道路用于练习导航，道路外也能自由驾驶；画面标出的“固定前轮圆”“普通对齐”“持续漂移／反打”是验证参考区，普通玩家流程不会强制切换固定转角。

| 区域 | 大致世界坐标 | 练习 |
| --- | --- | --- |
| 01 直道 | x=-11，y=24 到 -12；出生点 (-11,19) 向上 | 半速稳定、满速加速、松手停车 |
| 02 缓弯 | (-11,-12) 向上后向右至 (5,-28) | 提前选线、小幅转向免损保速 |
| 03 急弯 | (14,-28) 经 (21,-23) 回到 (15,-17) | 大角度掉速、普通与漂移路线对比 |
| 04 连续弯 | (13,-8)→(12,1)→(14,9) | 主动进漂、退出恢复、衔接下一弯 |
| 05 开放区 | (4,13) 周边，含多个木箱 | 碰撞归零、接触面侧向起步离开 |

障碍与边界都是实体。碰撞停在接触面、速度归零且不反弹；沿可通行方向重新推杆可转向脱离。完全封闭的死角用“重置 ↺”。重置会恢复出生位置、两种方向、速度、转向历史、镜头、输入与胎痕；仍按下的旧手指不会接管。

点击“验证模式”或打开 `/?validate=1` 可观察车型修订、路线／车头／运动方向、侧滑目标、实际前轮角、横摆、前后轴侧偏力、路面、保护和代价；参数单位、范围和不变量见 [PARAMETERS.md](PARAMETERS.md)。合法应用会完整重置，非法版本或组合保留当前配置，再用相同出生状态重复比较。

## 当前版本与升级边界

当前网页使用 `vehicle-physics-1`。权威状态保存位置、世界速度、车头角、横摆、前轮角、漂移混合、轮胎历史、辅助历史、能量和保护；速度与运动方向由世界速度派生，接入层不再维护第二套追赶模型。

驾驶链路按“路线意图 → 前轮转角 → 接地点轮胎力 → 车身横摆与速度向量 → 自动反打/回正 → 退出恢复”理解。摇杆角度始终是期望路线方向，辅助控制器负责有限转角、预测、侧滑反馈和出弯稳定；玩家不需要增加方向盘或反打按钮。正常几何转弯产生的质心夹角不等于漂移，只有实际接地点侧偏滑速并越过可见阈值才生成四轮胎痕。

验证面板显示：车型与修订、目标与实际前轮转角、车头方向、运动方向、实际／目标侧滑、横摆角速度、前后轴侧偏／侧向力／抓地占用、漂移混合量、路面、保护次数，以及动力／轮胎物理／游戏代价贡献。普通界面只显示实际速度和输入档。

## 验证场景入口

下列入口由网页场景标出，并可在无障碍核心基准中使用固定初态复查。它们不进入普通玩家流程，位置远离障碍，以便记录轨迹和状态，而不是播放固定动画。

| 入口 | 固定条件 | 必须观察 |
| --- | --- | --- |
| 几何圆 | 画面“固定前轮圆”区；核心验证入口固定正速度与前轮角，分别测试 `L=0.4` 与 `L=0.8`、前轮 ±20°/±30° | 后轴半径 `L/tan(delta)`、前后轴不同轨迹、半径与角速度误差 ≤3% |
| 普通对齐 | 目标速度为 Vmax 的 25%/50%/75%，左右 15°/45° 阶跃 | 3 秒内车头与运动方向误差 ≤2°，横摆 ≤3°/秒，前轮 ≤3°，保持 1 秒且速度 ≥目标 80% |
| 反打初态 | 速度与目标均为 0.65Vmax，`theta=+25°`、`motion=0°`、`r=+0.6rad/s`、`delta=+15°`、漂移混合量为 1；再用左/右镜像 | 0.8 秒内实际前轮角进入反向至少 2°；4 秒内方向误差 ≤3°、横摆 ≤4°/秒、前轮 ≤4°，保持 1 秒且速度 ≥目标 60%；默认硬保护为零 |

`/?test=1` 只提供可重复出生状态和开发快照，不改变普通输入含义；固定前轮属于核心验证选项，不会进入普通玩家流程。

## 升级后的车型与路面比较

`vehicle-physics-1` 已冻结十个配置 ID，验证模式的车型选择会从同一出生状态重置。车型选择只选择数据，不选择另一套物理算法；摇杆半径属于输入布局，车型参数不包含半径规则。

| 类别 | 配置 ID | 练习重点 |
| --- | --- | --- |
| 轻型车 | `light-pickup`、`heavy-pickup`、`van` | 目标速度、前驱/后驱差异、窄漂移 |
| 长车 | `box-truck`、`truck`、`heavy-truck` | 提前制动、长车头尾路线、较慢横摆 |
| 性能车 | `sports-car`、`rally-car`、`muscle-car` | 普通对齐、持续漂移、出弯恢复 |
| 越野车 | `off-road` | 松散地牵引、高质心的保守路线 |

核心和升级后的场景使用同一套 `vehicle-surface-1` 路面元数据：

| 路面族 | ID | 当前用途 |
| --- | --- | --- |
| 干硬路 | `dry-hard` | 默认基准、几何圆和普通对齐 |
| 松散地 | `loose` | 抓地降低、滚阻升高、拉力车与越野车比较 |
| 湿滑地 | `wet` | 更低抓地、连续弯和小幅修正比较 |

网页场地是一辆当前车型，包含干硬路、松散地和湿滑地区域；三类区域通过核心采样器改变抓地和滚阻，标签本身不会添加动画或速度加成。十车型可在验证模式切换，页面不模拟十辆车。

长车碰撞的验收对象是由轴距、车宽、前后悬生成的保守车身足迹，并覆盖平移和旋转扫掠；重卡是刚性单车身和前后等效轴，不包含挂车或独立多轴。接触停车后允许沿有空间的切向位移脱离，完全阻挡时撤回本步姿态且不原地旋转。完整重置清除速度向量、车头、横摆、前轮、漂移、辅助历史、输入、时钟、镜头、插值和胎痕。

## 文档入口与执行

普通网页入口和 `baseline-1` 操作见本文前半部分；核心无 DOM 入口按以下命令执行：

```powershell
npm run physics:benchmark
npm run physics:audit
```

命令输出应报告 `vehicle-physics-1`、`vehicle-profile-1`、十个车型、七对差异和三个路面族。独立核心报告不能替代网页接入、三视口触控、长车碰撞或真实手机验收；两类证据在 [验收记录](../openspec/changes/validate-driving-prototype/acceptance.md) 中分开保存。

## 完整重置规则

重置和参数应用同时清除位置、世界速度、车头、横摆角速度、实际/目标前轮角、漂移混合量、辅助控制历史、输入、时钟、镜头、插值和拖尾；页面隐藏时丢弃积压，恢复后不补算后台时间。
