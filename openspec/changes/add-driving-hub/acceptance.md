# 驾驶营地与装备视图验收

日期：2026-11-01。桌面浏览器与模拟竖屏验证，未连接真实手机。

## 实现与流程

- 默认首页进入驾驶营地，不弹副本准备页；出生点前方可看见商店、装备、出击的建筑招牌及停车框。营地使用已有试车场道路、碰撞与装配物理，主视口占 60%。
- 实际 Pointer Events 摇杆从 (-11,19) 北行进入装备区，释放并制动停稳后打开工作台；实际停车位置、速度与命中区域记录在 `evidence/driving-entry.json`。
- 停稳 0.7 秒、速度阈值、输入释放、打断重置、离开外扩边界后重入均有单元测试。关闭后停在原地不会重开。
- 商店购买实际扣款并增加库存；打开期间营地模拟停止。装备增加装甲并保存后，营地质量增加 80 kg，重载后装配一致。
- 缺发动机时仍能拖到装备区，购买发动机并按真实库存恢复布局后恢复驾驶。
- 出击区进入准备页；取消准备或结算保存成功后均可回营地，原练习入口仍可用。

## 装备视图与布局

- 底盘俯视与外观俯视共用车辆坐标；可辨认车头、车轮、车身、玻璃或底盘梁架。
- 每个装备实例只有一套完整图形和外周轮廓，多格内部没有格线。整体拖动、抓取格偏移、90° 旋转、八向武器朝向和非法重叠保留布局均通过浏览器验证。
- 320/390/430 宽竖屏的网格宽高差小于 0.1 像素；具体测量在 `../add-vehicle-ui/evidence/grid-*.json`，对应底盘和外观截图在同目录。营地与装备入口截图在本变更 `evidence/`。
- 目视检查后把小地图移到下方，避免遮挡出生点前方的出击区招牌，并重新生成三种尺寸的营地截图。
