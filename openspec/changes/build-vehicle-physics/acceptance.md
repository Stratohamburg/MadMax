# Acceptance

## Scope and Evidence

本记录只验收无DOM物理核心、十车型数据与独立基准。最终证据批次为 `f89663035784`，模型 `vehicle-physics-1`，配置 `vehicle-profile-1`，车型修订均为 `1`。汇总见 [summary-f89663035784.json](evidence/vehicle-physics-1/summary-f89663035784.json)；每车完整参数、全局规则、实现哈希、轮胎/方向/能量轨迹及矩阵位于 `<profileId>/1/core-f89663035784.json`。

路面版本为 `vehicle-surface-1`，控制器 `route-assist-1`，基准 `vehicle-benchmark-1`，输入 `vehicle-input-1`。运行 `npm run physics:benchmark` 可无浏览器复现；报告路径由运行方指定，默认只写本变更。旧 `validate-driving-prototype/evidence/` 经Git比较未修改，不覆盖baseline-1历史。独立 [audit-f89663035784.json](evidence/vehicle-physics-1/audit-f89663035784.json) 以当前源码哈希和逐车参数复核18,420个轨迹采样点，记录每份证据的SHA-256及原基线Git对象。

## Quantitative Results

下表为准静态默认配置中最慢普通矩阵项、左右恢复项的稳定窗口起点，之后都持续至少1秒满足共同误差及正速度门槛。非零轮胎瞬态同样通过完整矩阵；未放宽规划中的窗口。

| 肌肉车 | 1.650 / 3.5 | 1.558 / 4.5 |
| 越野车 | 1.758 / 4 | 1.342 / 5 |

默认跑车从规范指定±25°/±0.6rad/s/±15°/h=1初态退出，左右均在0.0583秒出现至少2°反向前轮，1.417秒进入稳定窗口。跑车持续漂移峰值约8.63°，最大路线误差约1.37°，侧滑参考误差小于0.65°；目标速度保持约99.97%，四种镜像/瞬态组合均持续3秒满足门槛。拉力也通过相同要求。

十车型三帧率差异全部为零。最大全局子步位置差约0.00443L、车头差约0.0668°，分别小于每车车长5%与2°门槛。零/单轴/双轴瞬态的无动力能量单步最大增益为零；预算及轴载荷守恒通过。所有默认普通、恢复、漂移、最终辅助路面与绕圆基准硬保护为零；极端边界允许且记录有界保护。

## Commands and Limits

- `npm run physics:benchmark`：本批次十车型与七对差异全部通过。
- `npm run typecheck`、`npm run build`：通过。
- `npx vitest run`：10个测试文件、77项测试全部通过，包含新核心与旧运行逻辑。
- `npm run physics:audit`：当前实现哈希/十参数快照/七对三辅助/18,420轨迹采样/载荷预算/原基线目录核对通过。
- `openspec validate build-vehicle-physics --strict`：通过。
- `git diff --exit-code HEAD -- openspec/changes/validate-driving-prototype/evidence`：通过，历史证据未修改。

合法边界测试覆盖0.1质量同比缩放、0.2/0.8质心比例配合受支持惯量、半轴距质心高、零高度、纯前/后驱动制动份额、后向/左右/漂移/停车。不是所有单字段极值都能任意组合；实际载荷幂律的最大有效刚度参与固定步长稳定界，超限组合明确拒绝。

无未解决的核心验收失败。轮胎瞬态是无弹性储能的被动近似，侧偏曲线及漂移包络为游戏模型；不宣称轮胎轮速、轮胎空转、差速器、挂车、侧翻或实车标定。默认sigma为零，但非零机制已独立通过同样数值/恢复与漂移要求。
