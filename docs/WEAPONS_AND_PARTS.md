# 武器与车辆配件目录

本文是武器与配件的**设计草案**，用于后续 `add-auto-weapons`、`add-vehicle-loadout-grid` 的数据定义。数值档位（极短…极长等）为相对等级，具体数值在平衡阶段确定。

## 1. 通用参数

### 1.1 所有部件（武器与配件）

| 参数 | 说明 |
| --- | --- |
| `id` / `name` | 稳定标识与显示名 |
| `layer` | 所属层：内层（车体内）/ 外层（车体外） |
| `shape` | 占用格形状，可旋转 |
| `mass` | **重量**（kg），影响质心、加速、操控与油耗 |
| `power` | 能耗（电池供电的部件） |
| `hp` | 耐久；外挂部件可被击落或脱落 |
| `tags` | 标签（供 roguelike 词条与被动触发引用） |

### 1.2 主动武器参数

| 参数 | 说明 |
| --- | --- |
| `trigger` | 触发类型：炮台 / 固定朝向 / 制导 / 被动 |
| `range` | 射程 |
| `arc` | 射界扇形角（固定朝向）或转角范围（炮台） |
| `spread` | 散布（弹道偏差角，使用可播种 PRNG） |
| `damage` | 单发伤害 |
| `pellets` | 单次发射弹丸数 |
| `fireRate` | 射速（发/秒） |
| `projectileSpeed` | 弹速 |
| `aoeRadius` | 爆炸/溅射半径（0 为单体） |
| `ammo` / `heat` | 弹药容量或过热上限/恢复阈值 |
| `recoil` | 后坐力冲量（经挂点产生平移与横摆） |
| `statusEffects` | 附带效果（如燃烧：持续伤害、时长、可叠加规则） |
| `targetRule` | 目标选择：最近 / 威胁最高 / 血量最低 |
| `powerDraw` | 从电池取电的功率（见 3.3） |

## 2. 武器

### 2.1 主动武器

| 武器 | 射程 | 散布 | 单发伤害 | 弹速 | 射速 | 范围 | 其他特性 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 喷火器 | 短 | 范围大（锥形） | 高 | — | 持续喷射 | 大 | **燃烧**效果；易过热；固定朝向 |
| 火箭弹 | 长 | 中 | 高 | 慢 | 慢 | 爆炸溅射 | 弹道可被拦截；后坐力大 |
| 霰弹枪 | 短 | 大 | **低（指单发弹丸）** | 中 | 慢 | — | 一次发射多颗（`pellets` 多）；总伤害取决于命中弹丸数 |
| 机枪 | 中 | 小～中 | 低 | 快 | 高 | — | 持续火力；可过热 |
| 机炮 | 中～长 | 小 | 中 | 快 | 中高 | 小溅射 | 机枪与加农炮之间；弹药消耗大 |
| 导弹 | 极长 | 极小 | 高 | 中 | 慢 | 爆炸溅射 | **制导类**：需在区域内保持锁定时长后发射；可追踪 |
| 加农炮 | 长 | 小 | 极高 | 快 | 极慢 | 溅射 | 炮台或固定；后坐力极大 |
| 刺枪 | 极短（近战） | 无 | 高 | — | 随撞击触发 | — | 外伸刺杆，靠车速撞击造成伤害，伤害随相对速度提升；可折断 |
| 勾索 | 中 | 无 | 低 | 中 | 极慢 | — | 命中后拉近/拖拽目标（或拉向目标）；绳索有强度与长度；控制类 |

### 2.2 被动型武器（事件触发，不需要目标）

| 部件 | 触发 | 效果与参数 |
| --- | --- | --- |
| 附加装甲 | 持续生效 | 提高对应方向的护甲；增加 `mass`，降低机动 |
| 爆炸反应装甲 | 受击 | 受击时爆炸抵消部分伤害并对近处造成伤害；**一次性/有冷却**，需 `cooldown`、`aoeRadius` |
| 铁丝网 | 被接触/撞击 | 对接触者造成持续伤害并减速；外挂，耐久有限 |
| 突刺 | 碰撞/被撞 | 对碰撞者造成反伤，伤害随撞击力；外挂，可折断 |
| 人（跳帮） | 贴近敌车 | 乘员跳上敌车进行攻击或破坏；占用**座位**；伤害低但可无视部分装甲；跳出后不可回收或需冷却 |

被动部件必须声明触发事件（受击、碰撞、击杀、漂移、速度阈值等）及内置冷却，防止无限触发。

## 3. 车辆配件（内层为主）

所有配件均有 `mass`（重量）参数。

### 3.1 座位
- 有座位才能载人（**包括驾驶员自己**）；无驾驶座的车无法被操控。
- 参数：`seatType`（驾驶位 / 乘员位 / 炮手位）、`capacity`、`mass`。
- 乘员是“跳帮”的来源，也可以操作指定炮位。

### 3.2 发动机
- 分气缸数与型号（如 L4 / V6 / V8 / V12）。
- 参数：`cylinders`、`model`、`maxPower`、`maxTorque`、`fuelConsumption`、`mass`、`heatTolerance`。
- 缸数多：功率与扭矩高，但更重、更耗油。

### 3.3 变速器
- 按档位数分级（如 4 / 5 / 6 / 8 档），按类型分手动 / 自动。
- 参数：`gearCount`、`type`、`gearRatios`、`shiftTime`、`efficiency`、`maxInputTorque`、`mass`。
- 手动：效率高、重量轻但换档存在损失；自动：易用、效率略低、更重。
- 需匹配发动机最大扭矩，否则受限。

### 3.4 电池
- 为武器及电子部件供电。
- 参数：`capacity`、`maxOutput`、`rechargeRate`、`mass`。
- 总供电不足时武器降低射速或停火。

### 3.5 油箱
- 决定续航。
- 参数：`fuelCapacity`、`mass`（含满油重量，油越多越重）、`hp`；被击中可能漏油或起火。

### 3.6 电台
- 参数：`range`、`channels`、`powerDraw`、`mass`。
- 用于通信、队友协同（联机）与情报共享。

### 3.7 潜望镜
- **驾驶位不在车体前方时必备**，否则视野受限。
- 参数：`viewAngle`、`viewDistance`、`mass`、`hp`；外露，易被击毁。

### 3.8 雷达
- 参数：`detectRange`、`detectArc`、`refreshRate`、`powerDraw`、`mass`。
- 提供索敌视野与制导类武器的锁定辅助；可被干扰。

### 3.9 车灯
- 参数：`lightRange`、`lightArc`、`powerDraw`、`mass`。
- 改善夜间或低能见度视野，同时更易暴露。

## 4. 配件依赖与约束

| 约束 | 说明 |
| --- | --- |
| 供电 | 武器、电台、雷达、车灯依赖电池；总 `powerDraw` ≤ 电池 `maxOutput` |
| 动力链 | 需要发动机 + 变速器 + 油箱才能行驶；变速器须承受发动机扭矩 |
| 载人 | 无座位则无人；无驾驶座则无法驾驶；驾驶位不在前方需潜望镜 |
| 总重 | 所有部件 `mass` 之和决定整车重量；超出底盘承载将影响加速与操控 |
| 外露 | 外层与外挂部件（武器、潜望镜、车灯、铁丝网、突刺等）可被击落 |

## 5. 待定事项

- 各档位数值与平衡（伤害、射程、重量等）。
- 勾索的拖拽物理细节与外力接口对接。
- 被动触发事件的完整列表，需与 `add-roguelike-modifiers` 标签体系同步。
- 机炮、导弹是否使用同一炮台/制导触发的细分。
