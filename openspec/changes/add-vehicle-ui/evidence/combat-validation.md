# 武器与敌人配置验收

日期：2026-11-01。当前工作区实现，尚未归档。浏览器使用本机Edge/Chromium能力；320/390/430是模拟视口，真实手机未连接。

## 实现与证据

- 九种武器共用装配SVG/战斗Canvas设计数据，各有完整轮廓、枪口、弹丸、拖尾与命中配置。机枪360°/143.2°每秒、重炮270°/51.6°每秒、机炮180°/91.7°每秒；固定/制导架不随目标瞬转。
- 炮管消费模拟瞄准角；地面细线指向实际炮口，全部提示保留1.5倍车身半径净空。武器本体可见于车辆。
- 七种敌人有各自生命、护甲、机动、武器和类型轮廓。静态建筑不移动，敌方只以真实弹丸命中造成远程伤害。
- 法向撞击速度达到1.2且真实接触时可撞死步兵，同时车体承伤；死亡、击杀和统计仅入档一次。
- 开火/命中/爆炸/死亡事件最多512条，展示特效最多256个。绘制和展示消费不改变战斗状态。

## 验证结果

- `npm test -- --run`：31文件、233项通过。其中 `combat-roster.test.ts` 的26项覆盖九种开火/命中、七种敌方攻击、枪口/转角、阵营、碾压、存档和30/60/120 FPS事件一致性。
- 全量Playwright：45项通过；敌人武器姿态计算优化后，战斗表现与工作台的14项再次通过。用独立临时结果目录避免并行验收清理默认产物。
- 炮口细线像素检查：重炮转动0.5秒后为0.45rad，未对准停火；实际朝向线的像素强度高于基准朝向，渲染前后状态相同。原净空像素测试也通过。
- `npm run build`、`openspec validate --all --strict`（11项）及 `git diff --check` 通过。
- [真实敌方武器桌面压测](../../add-combat-damage/evidence/desktop-roster-benchmark.json)：128敌人/2048弹丸，预热120步、测量600步；p50 1.6175ms、p95 2.8166ms、max 6.0150ms，敌方发射1564次，事件/特效上限512/256。只包含模拟与事件消费，不包含Canvas绘制及预填弹丸开销；不作为手机性能结论。
