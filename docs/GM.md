# GM 调试工具

营地主界面右上角点击“GM”进入面板。该入口用于当前本地原型，可在手机和桌面浏览器使用；副本战斗中没有 GM 入口。打开期间暂停营地驾驶，关闭时清除输入并刷新车辆耐久状态。

新建档案及 GM 重置后的初始跑车所有部件均为满耐久，已在车顶中央安装一挺机枪，另有弹药箱、电池及必要驾驶/动力部件，初始资源为 250 货币、100 废料。营地直接显示实际挂载武器。已有战斗损伤会继续保存，可在 GM 中选择“一键修复全部装备”恢复库存全部零件的最大耐久，不扣资源、不改等级和布局；丢失零件可重新发放后在工作台安装。

## 发物资

- 货币和废料：选择数量后分别发放，单次 1～1000000 的整数，累积结果必须为安全整数。
- 零件：选择任意已有配置的零件及数量，单次 1～100 件；每件是独立、L0、满耐久实例，进入仓库后手动安装。
- 每次成功操作立即保存本地档案，并显示当前资源和仓库数量。非法输入或保存失败会报错，原数据不变。

## 重置数据

勾选“确认清空全部本地进度并重建初始车辆”，再点击“重置数据并返回营地”。库存、资源、装配方案、解锁、主线和统计会清空并重建为初始状态；同时替换主存档与备份、移除待处理结算，避免旧进度在重启时恢复。只有写入成功后才返回营地，失败保留旧档且可以重试。

数据操作位于 `src/persistence/gm.ts`，重置通过 `ProfileRepository.reset()` 的单次事务完成；发放和修复复用普通档案事务与格式校验。普通启动不会自动重置、补造或修复装备。

验证：`npx vitest run tests/unit/gm.test.ts`、`npx playwright test tests/e2e/gm.spec.ts`。320、390、430 宽度的营地机枪及 GM 面板截图位于 `openspec/changes/add-gm-tools/evidence/`；浏览器验证不替代真机验收。
