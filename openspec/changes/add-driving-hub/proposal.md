# Proposal

## Why

当前入口直接打开副本准备页，商店与装备埋在同一个对话框中，缺少可驾驶的游戏主界面。玩家需要从试车场改造的营地出发，开到出生点前方的功能区域、停稳后自然进入。

## What Changes

- 默认首页改为基于现有试车场的可驾驶营地，前方设置商店、装备与出击区域。
- 车辆进入区域并松开摇杆、停稳后自动打开对应界面；关闭后需离开区域再进入才会再次触发。
- 独立商店消费现有库存与交易规则；装备保存后更新营地车辆，出击进入既有副本。
- 副本准备与结算均可返回营地；独立物理验证场使用明确的练习入口。

## Capabilities

### New Capabilities

- `driving-hub`：可驾驶营地主界面、停稳交互区域、商店/装备/副本导航及返回流程。

### Modified Capabilities

无，现有驾驶能力尚处于未归档变更，物理行为保持现有契约。

## Impact

新增 `src/modes/hub/` 和独立商店 UI，扩展入口路由与绘制配置，复用固定时钟、装配驾驶、Canvas 与 IndexedDB 档案。装备俯视图的细化单独追加到现有 add-vehicle-ui。
