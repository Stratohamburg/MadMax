# 驾驶练习

进入网页就能开车。右上角 `?` 可随时打开操作说明。摇杆中心固定，屏幕方向就是想去的方向，镜头只跟随车辆位置。车头会逐渐转向；推向后方会向前转弯掉头。

1. 从中心向上推到实线内环一半，目标为半速；车辆需要时间加速，保持后能稳定半速。任意微小位移都有速度，精确回中才是零输入。
2. 实线内环是普通满油门，再向外还有缓冲行程。缓冲区能保持最高目标速度，且仍是普通抓地。
3. 继续推到外侧虚线环，进入漂移；轻微回收仍保持漂移，收回点线退出环以内恢复普通满油门。所有方向均可外拉，不需要额外按钮。
4. 漂移时车头先变、路线随后跟上；退出时侧滑逐渐消失。小幅转向保速，大角度转向会掉速，漂移代价更大。满油门只表示目标速度，HUD 是实际速度。
5. 松手逐渐停车。触控取消、页面切走、尺寸变化会清除输入，回来需重新触碰。

地图右上角小地图数字对应以下区域，点表示车辆当前位置，北方向始终向上。道路用于练习导航，道路外也能自由驾驶。

| 区域 | 大致世界坐标 | 练习 |
| --- | --- | --- |
| 01 直道 | x=-11，y=24 到 -12；出生点 (-11,19) 向上 | 半速稳定、满速加速、松手停车 |
| 02 缓弯 | (-11,-12) 向上后向右至 (5,-28) | 提前选线、小幅转向免损保速 |
| 03 急弯 | (14,-28) 经 (21,-23) 回到 (15,-17) | 大角度掉速、普通与漂移路线对比 |
| 04 连续弯 | (13,-8)→(12,1)→(14,9) | 主动进漂、退出恢复、衔接下一弯 |
| 05 开放区 | (4,13) 周边，含多个木箱 | 碰撞归零、接触面侧向起步离开 |

障碍与边界都是实体。碰撞停在接触面、速度归零且不反弹；沿可通行方向重新推杆可转向脱离。完全封闭的死角用“重置 ↺”。重置会恢复出生位置、两种方向、速度、转向历史、镜头、输入与胎痕；仍按下的旧手指不会接管。

点击“验证模式”或打开 `/?validate=1` 可观察与调参；参数单位、范围和不变量见 [PARAMETERS.md](PARAMETERS.md)。观察三条方向线和速度贡献，再用相同出生状态重复比较。
