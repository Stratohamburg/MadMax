# 驾驶练习与验证

当前网页运行 `vehicle-physics-2`。摇杆距离和方向都表达期望，控制器根据车辆能力给出转向、动力和制动，实际速度与轨迹由物理决定。HUD 显示实际速度。

1. 向想去的屏幕方向推杆，距离越远目标速度越高；实线内环一半表示半速。车辆需要时间加速和转弯，非零位移没有中心死区。
2. 实线内环达到最高目标速度，继续外拉的缓冲区仍属普通辅助。普通控制会根据车型、速度、载荷与路面限制前轮请求，急转时允许暂时达不到期望路线。
3. 外拉至虚线环进入漂移辅助，略微回收仍保持；收回点线退出环以内退出。漂移放宽转向等控制限制，并通过动力、后轴制动和反打促成真实侧滑，不直接改变车辆姿态或轮胎材质。
4. 漂移消耗动能，动力请求仍有效，会改变轮速、抓地分配和轨迹；推到最远也不保证保持最高实际速度。退出后控制器尝试恢复，侧滑和横摆连续演化。
5. 松手请求停车。页面切走、触控取消或尺寸变化清除输入，回来需要重新触碰。

普通辅助只能预防它自己在稳定驾驶中诱发失稳。撞击、抓地突变或已经失控时，普通模式同样可能倒滑或 spin；辅助会尽力恢复。静止打轮本身不会让车原地旋转，但撞击遗留的旋转会继续由摩擦耗散。

镜头只跟随位置，不随车头旋转。地图中的直道、缓弯、急弯、连续弯和开放区用于练习，路外也能驾驶。固定前轮圆、普通对齐、持续漂移/反打是验证参考区，不会在玩家进入时强制切换车辆状态。左上区域为松散地，右上区域为湿滑地，其余默认干硬路。

障碍使用由车型几何生成的矩形车身及平移、旋转扫掠检测。接触点冲量会改变平移和横摆；擦墙会保留可行的切向运动，偏心撞击可能甩尾。碰撞不按摇杆方向注入逃离速度，也不统一清零整车状态。封闭死角使用右上角重置。

重置及参数应用会清除车辆、轮速、控制历史、能量、输入、时钟、镜头、插值和胎痕。旧触点即使仍按着也不能接管，需重新触碰。

点击“验证模式”或打开 `/?validate=1`，可以切换十车型、修改参数，并观察实际/目标速度、世界路线、车头、运动方向、侧滑、前轮、横摆、轴载荷、组合抓地利用率、轮速、控制饱和和能量收支。漂移模式是辅助策略请求，实际漂移需要结合侧滑与接地点滑移判断。

车型包括轻型/重型皮卡、van、厢式货车、卡车、重卡、跑车、拉力、肌肉车和越野车。长车需要更多转弯空间和制动提前量；所有车型使用同一个求解器。重卡是刚性单车身加前后等效轴，未模拟挂车。

`/?test=1` 仅在开发模式提供可重复初态，包括轮速、横摆和已有失控状态。自动化覆盖三视口触控、重置、十车型切换、碰撞及失控惯性；30/60/120 FPS 回放与物理基准分别执行。真实手机驾驶未执行，浏览器仿真不能替代手感验收。

```powershell
npm run physics:audit
npm run validation:replay
npm run test:e2e
```
