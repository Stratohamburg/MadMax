# Proposal

## Why

车辆控制已可用，但车辆只能从十个固定车型中选择。改装是游戏的核心成长与 build 载体：玩家在车体俯视图上摆放零部件与武器，摆放位置决定后续的质心、武器射界和风险。需要先定义纯数据、无 DOM 的格子装配模型，供物理、武器、存档和 UI 共同消费。

## What Changes

- 新增底盘格子定义：每个底盘由**内层（车体内剖面）**与**外层（车顶与外挂硬点）**两个独立格子层组成。两层格子上下空间对齐，且**外层几何范围在四周比内层外扩一圈**（用于容纳车头撞角/刺枪、车侧外挂装甲/机枪与车尾硬点），格子带槽类型、可用性与外露朝向。
- 新增部件数据模型：多格形状、可旋转、槽类型、质量、能耗、标签、外露属性与耐损基础数据。
- 简化能源与弹药拓扑：不设网格物理连线与供弹管路，采用整车**全局总供电与总弹药池**统一供给。
- 内层摆放车辆内部构件（发动机、变速箱、电池、油箱、座舱/乘员舱、内装甲等）；外层摆放武器、车顶构件与外挂装甲。
- 新增车型出厂预设清单：为十种现有车型提供默认预设装配（Stock Presets），支持一键还原，同时支持玩家自由拖拽移动、旋转、替换与卸下。
- 新增装配合法性校验与摆放纯函数操作（放置、移动、旋转、移除）及可稳定版本化序列化的装配清单。
- 不含 UI 绘制、物理换算、武器行为与存档（由后续变更负责）。

## Capabilities

### New Capabilities

- `loadout-grid`：底盘两层格子、部件形状与槽约束、摆放校验、装配清单及其稳定序列化。

### Modified Capabilities

无。

## Impact

新增无 DOM 模块（如 `src/loadout/`）与单元测试；不修改 `src/vehicle/physics`。后续 `add-assembly-physics`、`add-auto-weapons`、`add-progression-persistence` 依赖本能力的装配清单与坐标合同。本变更是改装系列的起点。
