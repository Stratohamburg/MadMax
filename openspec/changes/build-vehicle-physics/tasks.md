# Tasks

本变更只跟踪物理核心、车型配置和独立基准实施，实施状态以复选框与 acceptance.md 的证据引用为准。验证场的触控、车型选择界面、绘制、长车碰撞和真机由 validate-driving-prototype 跟踪；其接入不得复制本模型。每组随实现交付相应测试和说明，最后一组只做整体核对。

## 1. Contracts and Parameters

- [x] 1.1 建立无DOM物理公共合同、完整状态／观测和一致初态工厂，speed／motion只读派生；以无浏览器运行、拒绝矛盾注入及相同参数换标签结果一致测试验证，记录API说明。
- [x] 1.2 实现vehicle-physics-1、vehicle-profile-1及profileId／revision版本，拆分全局、车型、路面与验收元数据；测试拒绝baseline-1／旧规划格式、不完整对象及部分生效，交付格式说明和参考快照。
- [x] 1.3 实现参数单位、合法范围与跨字段校验，覆盖几何、m／Iz、峰值滑动、驱动／制动份额、低速区间、瞬态稳定和全局尺度；用合法边界与非法组合测试验证错误可定位且当前有效配置保留。
- [x] 1.4 明确质量与单位归一、F/m和Iz/(mL²)派生值及字段唯一来源；以质量相关量同比缩放响应不变、只增质量而不增动力提速下降测试验证，更新参数调校说明。

## 2. Geometry and Axle Loads

- [x] 2.1 实现轴距、质心前后比例、车宽／前后悬、四轮位置及保守占地输出；测试轴在车身内、切换长车输出同步与各消费者坐标约定，记录等效轴／刚性重车边界。
- [x] 2.2 实现纯低速几何与固定前轮验证入口；用合法L=0.4／0.8、V=0.3、左右20°／30°检查后轴半径、轴距比例和前后轴路径，误差不超过3%。
- [x] 2.3 实现低速阿克曼显示角派生；测试内轮大于外轮、左右镜像、直行极限和最大角合法分母，文档说明单轨力与四轮显示的关系。
- [x] 2.4 实现hCG与物理纵向作用的准静态载荷转移、因果历史和合法边界；测试加速后移、制动前移、零高度／零作用特例、轴载荷非负及总量守恒，不把游戏损失混入估计。
- [x] 2.5 实现前轮执行器有限行程、响应与转角速度；测试静止打轮不转车身、右左切向过零和高速行程限制，交付转向及载荷参数说明。

## 3. Tires and Surfaces

- [x] 3.1 实现每轴侧偏、刚度、峰值／滑动段连续曲线及关闭峰后下降特例；测试正负扫描、零侧偏、峰位、连续性、力有界与参数关联，交付曲线与参数说明。
- [x] 3.2 实现纵横抓地椭圆及驱动／制动占用，处理零预算；测试合力不越界、增加纵向占用降低侧向能力，准静态力方向阻碍实际侧滑。
- [x] 3.3 实现标称载荷规律与可关闭载荷敏感度；用载荷扫描验证刚度／μ变化、零系数基准和预算，说明前后载荷变化与未实现的左右载荷转移区别。
- [x] 3.4 建立前后轴路面采样、三类路面和轮胎适应参数，默认采样显式返回干硬路；测试两轴跨边界分别生效、低抓地即时预算、状态连续及同参数不按名称换算法，记录路面版本格式。
- [x] 3.5 实现可关闭前后轴轮胎松弛及稳定离散、储能／耗散核算；比较零／单轴／双轴σ的阶跃和反打，测试低速、预算下降、无动力总能量及子步收敛，交付瞬态开关与限制说明。

## 4. Dynamics and Speed Control

- [x] 4.1 实现前后轴力坐标转换、世界速度与横摆惯性积分；测试左右符号、同力矩惯量翻倍、反打不立即翻转r及无力直行，不用直接改车头／追赶运动角。
- [x] 4.2 实现随速度变化的动力／制动请求、轴分配、滚阻与可选风阻，经过轮胎预算后积分；测试低高速曲线、半速稳态、目标夹断、小正目标及有限停车，分开记录驱动和阻力，更新动力说明。
- [x] 4.3 实现低速到动力学的连续导数过渡，含前轮变化和轮胎历史处理；测试跨区、重复起停、侧向起步、零速横摆为零及正常几何侧偏不误判。
- [x] 4.4 实现1/120外步与两次1/240中点RK2子步，瞬态采用兼容稳定更新；对参考车执行1/480收敛、无动力能量与帧率回放，记录允许参数组合和数值说明。
- [x] 4.5 实现可观测软稳定与极端前进约束，不每步夹运动角；测试后向目标、急转与合法边界，正常基准硬保护为零，交付保护字段及失败诊断。

## 5. Route and Drift Assistance

- [x] 5.1 实现路线chi／车头theta／侧滑beta分离的预测与稳定角差，按精确180°规则生成有界路线参考；测试179°跨界、后向选择、无目标不追旧路线和不同标签不改变参考规则。
- [x] 5.2 实现正常稳态侧偏与中高速前馈／增益调度，先做无辅助和公共辅助绕圆标定；记录欠转／过转指标，验证不把低速几何参考全速外推，不让辅助抹平物理差异。
- [x] 5.3 实现漂移目标侧滑、速度／转弯需求包络、连续进入与恢复，以及路线／侧滑／横摆反馈到实际前轮；测试直线入漂无凭空横滑、目标归零、持续侧滑正速度窗口，交付输入语义与辅助调参说明。
- [x] 5.4 通过默认跑车普通对齐和左右镜像反打矩阵，包含3秒普通、0.8秒反向前轮、4秒恢复及持续1秒正速度要求；同时测试完整入漂到出弯和轮胎瞬态开关，不靠清r或夹姿态通过。
- [x] 5.5 实现独立游戏意图代价与普通／漂移lambda，按路线目标与车头夹角计算；固定原态测试免损、45／90／120／180°、模式差异、无目标为零、满油门掉速及持续漂移仍承担代价，更新损失说明。

## 6. Vehicle Profiles and Calibration

- [x] 6.1 建立提速、制动、固定转角、路线阶跃、稳定、漂移及路面适应基准与机器可读报告；验证公共速度定义、相对差算法和指标族去重，交付调校顺序与基准命令说明。
- [x] 6.2 配置并调校轻型皮卡、重型皮卡和van，填完整参数、单位与响应窗口；分别跑全部基准和稳定／能量检查，提交快照及未通过项，不能只换名称。
- [x] 6.3 配置并调校厢式货车、卡车和重型卡车，验证长轴距、占地、动力重量比和恢复节奏；提交三者完整快照、等效轴边界、响应窗口及基准证据。
- [x] 6.4 配置并调校跑车、拉力赛车、肌肉车和越野车，验证干路／松散地、驱动分配与漂移包络；提交完整快照和基准，跑车／拉力须通过设计中的持续侧滑窗口与路线误差门槛。
- [x] 6.5 对指定七对相近车型完成至少两个不同指标族≥15%差异的报告，分别记录无辅助／公共辅助／最终辅助结果；未满足项继续调校，不用最高速度或同族重复计数通过。
- [x] 6.6 冻结十车型各自普通／恢复窗口、合法漂移初态及参数修订；在各自窗口内复跑相同残余误差、1秒正速度和硬保护零要求，交付车型配方与游戏近似说明。
