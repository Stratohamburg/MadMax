# 自动武器

`src/combat/weapons/` 提供无 DOM 的四类触发与九种已接入武器。`createWeaponSystem(composition, seed)` 创建可序列化状态，`stepWeapons` 每次固定推进 1/120 秒，返回新状态、开火事件、后坐力和展示数据。驾驶输入不包含开火命令。

## 当前武器配置

数值来自 `definitions.ts`；射程/速度使用游戏长度，伤害为未应用装配、暴击及目标防御的基础值。`arc`、`turnRate` 在代码中分别使用弧度、弧度/秒，下表换算为角度。固定武器的射界用于检测目标，炮口跟随安装朝向。

喷火器另附每秒6点、持续2秒的燃烧。机枪/机炮/导弹/喷火器分别用电8/10/18/12；导弹与火箭消耗火箭弹，其余弹药武器消耗弹道弹药，机炮每次2发。突刺和反应装甲为事件武器，不消耗弹药。

九种武器的完整轮廓、颜色、枪口偏移、弹丸样式、拖尾、火光和命中尺度统一位于 `presentation.ts`，同时供装配 SVG 和战斗 Canvas 使用。武器本体可见于车上，炮台基座随车体转动，炮管消费实际瞄准角；有限射界炮台不会穿越禁止转角，也不会瞬间指向目标。导弹架保持固定朝向，导弹自身有限转速制导。

## 触发和目标

- 炮台：射程与允许转角内索敌，以有限转速对准，误差不超过 0.04 rad 才射击；全转角炮台可以跨越 ±π，有限转角炮台沿允许区域内旋转。
- 固定：车体与挂点朝向形成扇形，目标进入扇形才射击。
- 制导：相同目标持续保持锁定，切换目标归零；离开时由定义选择清零或衰减，开火后重置。弹丸事件包含制导目标与转速，弹丸运动由战斗核心负责。
- 被动：hit、collision、kill、drift、speed、boost 事件，带递增 sequence 和 magnitude；按阈值触发，记录已消费序号并施加内置冷却，避免同事件递归触发。

目标查询只需实现 `TargetQuery.query(center, radius)`。目标选择支持 nearest、threat、lowest-hp，平局按整数实体 ID 升序。武器使用 compose 提供的质心相对挂点，通过 `worldMount` 换成世界位置。

## 整车供给与损伤

弹药按类型保存在整车状态中，电量共用；武器按稳定实例 ID 顺序消耗。供电不足时，有耗电的武器按整车最大输出/总需求比例降低有效射速。单发耗能为额定功率/基础射速，电量或弹药不足不发射，不产生负资源。

每步降低冷却和热量，达到热量上限后停火，降到恢复阈值才解除。一个固定步可以发出多次开火事件。受损武器射速减半、散布加倍，毁坏武器不参与开火。伤害、射速、射程、弹数和散布通过共享分层属性规则求值。

## 事件与展示

`FireEvent` 包含武器实例、实际枪口世界坐标、目标、每颗弹丸的方向、速度、伤害类型、爆炸范围、穿透、寿命和燃烧/制导参数。射界从挂点计算，发射从枪口计算；后坐力仍作用于真实挂点。散布使用可保存整数状态的 xorshift32。战斗结算消费这些事件，武器模块不直接减敌人血量。

`RecoilEvent` 是世界冲量与世界挂点，可传给 `applyExternalImpulse`。`WeaponVisual` 包含基准/瞄准角、射界、射程、锁定目标、装填外沿和过热进度。车身中心 1.5 倍保守半径为净空区；UI 必须在射界外沿显示状态并裁掉净空区，不能在车顶堆放进度条。
