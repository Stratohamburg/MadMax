# 车库与战斗反馈

从 `/?mode=pve` 准备页进入“装配工作台”。上方“车内剖面 / 车顶外饰”切换层，透视显示另一层。网格车头朝上，虚线为外沿槽。部件从仓库拖入，或先点击仓库再点击格子；已经安装的部件可拖动。旋转改变形状，朝向以 45° 改变武器朝向，二者独立。非法摆放显示核心原因并保留原布局。

看板实时更新质量、质心、轴荷、动力、极速、抓地、供电、燃料和弹药。耐久和升级等级参与计算，缺少可用驾驶座、发动机、变速箱或油箱时禁止使用装配。可以购买、升级、维修实例或解锁底盘；资源不足时档案不变。升级至 L 级消耗 50L 货币 / 10L 废料，最高 5 级；每级火力或发动机动力 +5%。

填名称后“保存方案”新建独立方案；选中方案后加载或删除。“保存并使用”把当前装配存为出击装配，刷新仍可恢复。“还原出厂布局”只重排已有库存，缺失件不会补造。副本内没有改装入口。

战斗左下显示原装配布局的纸娃娃：绿色正常，黄色闪烁为半血以下降效，红叉为毁坏失效，虚线缺口为外露件脱落，并有可读状态说明。减少动态效果系统设置会关闭闪烁。右上小地图保留，中央驾驶视线净空。

射界投影于地面。所有武器提示经过共同的 1.5 倍车体包围半径净空裁切，并添加一逻辑步移动余量；近距离准星隐去。装填和热量弧位于射界外沿，不在车顶堆叠状态条。伤害按目标/类型/0.2 秒窗聚合，最多 24 条，0.8 秒回收，净空内不显示；显示聚合不改变结算。

结算页在保存成功前禁用返回准备，失败显示重试入口。IndexedDB 保存仍以唯一 runId 保证幂等。

验证：`npx playwright test tests/e2e/vehicle-ui.spec.ts`；320、390、430 像素竖屏证据见 `openspec/changes/add-vehicle-ui/evidence/`，包含网格编辑、真实存档重载、失败重试和净空像素检查。真机手感与压测继续在原待办中单独验收。
