# Proposal

## Why

游戏的爽感来自后期倍率提高后的大量弹丸与巨额伤害，同时需要敌人、血量、装甲、碰撞伤害等基础战斗循环。需要一个高吞吐、确定性、可测试的战斗核心，并尽早在手机上验证性能上限。

## What Changes

- 新增战斗实体：玩家车辆、敌人、弹丸、爆炸/范围效果；血量、装甲（内/外层装甲与外挂部件耐久）。
- **新增模块两段式受损状态机（Damaged vs Destroyed）**：
  - **受损状态（Damaged, HP ≤ 50%）**：部件发生性能衰减，但不丧失全部功能（如发动机马力降为 50%、变速箱换挡耗时加倍、武器射速降低且散布加大、电池最大输出减半）。
  - **毁坏状态（Destroyed, HP = 0）**：部件彻底失去功能（发动机完全失去动力、外挂武器脱落或报废哑火、油箱起火或殉爆、电池彻底断电）。
- **新增战地应急维修机制**：
  - 随行机械师：作为占用车内座舱/乘员舱格子的功能乘员，在战斗中自动缓慢抢修受损（Damaged）部件，但无法独立复原已毁坏（Destroyed）部件。
  - 荒野移动维修区：作为废土道路上的移动支援车或维修驿站，进入其维修光环可快速修理、补满弹药，并能将毁坏（Destroyed）部件应急修复至 50% 可运转状态。
- 新增伤害管线：基础伤害 → 倍率栈（加算/乘算分层）→ 暴击 → 抗性/装甲减免 → 结算。
- 新增外挂部件受击与脱落、碰撞伤害（利用现有碰撞冲量）。
- 新增弹丸池、空间哈希与上限策略，以支持大量弹丸；伤害数字与特效事件聚合输出。
- 新增手机性能压测基准（弹丸数量、敌人数量、帧时间）。
- 不改变渲染方案（继续 Canvas 2D，仅输出渲染所需的最小数据）。

## Capabilities

### New Capabilities

- `combat-damage`：战斗实体、伤害管线、两段式损毁状态机、战地维修机制（机械师与移动维修区）、装甲/外挂耐久、弹丸池与确定性战斗步进、性能预算。

### Modified Capabilities

无。

## Impact

本次细化增加步兵、武装车辆、固定碉堡和重装首领的配置目录，统一远程武器、受击和死亡表现；撞击步兵可击杀且玩家车辆承伤，建筑保持静止。

新增 `src/combat/`（实体、伤害、弹丸、空间索引）与压测脚本；需与现有场景/碰撞模块对接，战斗步进接入固定外层时钟。依赖 `add-auto-weapons` 的开火事件，被 `add-roguelike-modifiers` 与 `add-pve-extraction-mode` 使用。
